# 📷 Camrotate
Isn't it so annoying in some first person mods where the body doesn't rotate with the camera? Well, here's a mod just for you!

All this mod does is rotate your body to where your camera is looking, similar to other games in first person.

This is mod is best used with [First Person Model by tr7zw](https://modrinth.com/mod/first-person-model)
